업데이트 알림이 서버 입장 중에 사라지던 문제 수정, 남아 있던 Together Plus 데이터 정리

마인크래프트 1.21.4 (Fabric) · 필요한 모드: Fabric API

### 🐞 고친 문제
- **업데이트 알림**: 리소스팩 내려받기나 대기실을 거쳐 들어가면 알림이 지워져 보이지 않던 문제를 고쳤어요. 이제 게임 화면에 들어오고 잠시 뒤에 알림이 떠요.
- **Together Plus 데이터**: 예전 버전에서 기록된 Together Plus 데이터 메시지(`~tp…`)를 기록에서 지워요. 그 메시지만 있던 대화는 목록에서 사라져요.

### 📥 설치
`mods` 폴더의 예전 `chattingplus-*.jar`를 지우고 아래 Assets의 `chattingplus-1.1.4.jar`를 넣어 주세요.
