팝업에 새 메시지가 안 보이던 문제, 재접속 뒤 말풍선 옆 빈 공간 수정

마인크래프트 1.21.4 (Fabric) · 필요한 모드: Fabric API

### 🐞 고친 문제
- **새 메시지가 안 보임**: 기록이 가득 찬 대화(채널 500개, 귓속말 1000개)에서 채팅을 쳐도 팝업·대화창에 새 메시지가 보이지 않던 문제를 고쳤어요. 이제 기록을 지우지 않아도 바로 보여요.
- **말풍선 옆 빈 공간**: 서버에 다시 들어가면 말풍선 오른쪽에 빈 공간이 생기던 문제를 고쳤어요. 서버 리소스팩이 다시 적용되면 말풍선 폭도 다시 맞춰요.
- **내 닉네임 착각**: 채널 채팅에서 다른 사람이 내가 친 말과 같은 말을 먼저 치면, 그 사람을 나로 잘못 기억해 말풍선 위치가 뒤바뀌던 문제를 고쳤어요.

### 🔧 바뀐 점
- **설정 저장**: 조정 바를 끌 때 게임이 살짝 끊기던 것을 줄였어요. 저장 도중에 게임이 꺼져도 설정이 초기화되지 않아요.
- **내 닉네임**: 서버마다 따로 기억해요.

### 📥 설치
`mods` 폴더의 예전 `chattingplus-*.jar`를 지우고 아래 Assets의 `chattingplus-1.1.5.jar`를 넣어 주세요.
