팝업 전용 키(Y)와 시스템 탭 추가, Together Plus 호환

마인크래프트 1.21.4 (Fabric) · 필요한 모드: Fabric API

### ✨ 새 기능
- **팝업 전용 키 (기본 Y)**: 바닐라 채팅(T)을 열지 않고 팝업 채팅창에 바로 입력해요. 팝업 바깥을 클릭하면 게임으로 돌아가요.
- **시스템 탭**: 전체·지역·마을 채팅과 귓속말을 뺀 나머지 메시지가 모두 모여요. 입력은 바닐라 채팅처럼 돼요(`/명령어` 가능).
- **팝업 탭 순서 바꾸기**: 탭을 끌어서 순서를 바꿀 수 있어요.
- **팝업 표시 위치 설정**: 팝업을 서버 화면 표시(보스바 안내 등) 위에 그릴지 아래에 그릴지 고를 수 있어요.

### 🔧 바뀐 점
- 설정의 조정 바가 1 단위로 더 세밀하게 움직여요.
- 업데이트 알림과 모드 메뉴의 웹사이트 버튼이 카페 소개 글로 연결돼요.

### 🐞 고친 문제
- 서버가 보스바로 띄우는 안내("마을채팅(/ㅁ)" 등)가 팝업 자리에서 구멍 난 것처럼 보이던 문제
- Together Plus를 같이 쓸 때 데이터 메시지(`~tp…`)가 채팅창에 쌓이던 문제

### 📥 설치
`mods` 폴더의 예전 `chattingplus-*.jar`를 지우고 아래 Assets의 `chattingplus-1.1.2.jar`를 넣어 주세요.
