팝업 바깥을 눌러도 화면이 닫히지 않게 수정 (Together Plus 호환)

마인크래프트 1.21.4 (Fabric) · 필요한 모드: Fabric API

### 🔧 바뀐 점
- **팝업 전용 키(Y) 화면**: 팝업 바깥을 클릭하면 입력칸 선택만 풀리고 화면은 그대로 열려 있어요. Together Plus 같은 다른 모드의 화면을 그대로 클릭할 수 있어요.
- **나가기**: Esc를 누르거나, 입력칸 선택이 풀린 상태에서 Y를 한 번 더 누르면 게임으로 돌아가요.

### 📥 설치
`mods` 폴더의 예전 `chattingplus-*.jar`를 지우고 아래 Assets의 `chattingplus-1.1.3.jar`를 넣어 주세요.
